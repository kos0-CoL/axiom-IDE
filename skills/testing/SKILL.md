# SKILL: testing

Objetivo: tests unitarios, de integración y E2E.

## Cómo trabajar con esta skill
Escribe y ejecuta tests (unit/integración/E2E). Cubre casos borde y caminos de error. Mantiene la suite verde; no debilita aserciones para pasar.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
