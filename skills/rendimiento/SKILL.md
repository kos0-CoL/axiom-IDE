# SKILL: rendimiento

Objetivo: medición con umbral antes de afirmar una mejora.

## Cómo trabajar con esta skill
Define el umbral (latencia, memoria, consultas), toma una línea base y compara con la misma carga y el mismo entorno. Reporta número, comando y condiciones. Si no puedes medir, dilo: no estimes como si fuera una medición.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
