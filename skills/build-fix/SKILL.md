# SKILL: build-fix

Objetivo: reparación mínima de build y tipos.

## Cómo trabajar con esta skill
Arregla errores de build/tipos con cambios mínimos; sin refactors ni cambios arquitectónicos. Objetivo: build verde rápido.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
