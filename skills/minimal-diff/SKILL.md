# SKILL: minimal-diff

Objetivo: cambio mínimo que resuelve el problema.

## Cómo trabajar con esta skill
Hace el cambio más pequeño que resuelve el problema. No toca código no relacionado. Facilita revisión y rollback.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
