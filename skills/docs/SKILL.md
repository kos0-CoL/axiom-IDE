# SKILL: docs

Objetivo: documentación alineada al comportamiento real.

## Cómo trabajar con esta skill
Actualiza solo la documentación que el cambio deja obsoleta (README, referencias, OpenAPI, decisiones). Verifica cada afirmación contra el código o una ejecución real. Documenta comportamiento, no intención.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
