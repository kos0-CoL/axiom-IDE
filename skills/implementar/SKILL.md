# SKILL: implementar

Objetivo: implementación de código.

## Cómo trabajar con esta skill
Escribe código coherente con el stack del proyecto. Prefiere archivos nuevos salvo que el cambio exija reemplazo; anuncia qué archivos toca y qué criterio cumple.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
