# SKILL: sec-hardening

Objetivo: hardening de servicios y contenedores (mínimo privilegio, puertos, secretos).

## Cómo trabajar con esta skill
Revisa el hardening: mínimo privilegio, usuario no-root, filesystem read-only, puertos expuestos, secretos fuera de imágenes y flags de seguridad del runtime (Dockerfile, compose, unit files). Cita archivo y línea; cada hallazgo lleva el cambio concreto que lo cierra.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
