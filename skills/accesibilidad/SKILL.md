# SKILL: accesibilidad

Objetivo: revisión de interfaz con criterios WCAG.

## Cómo trabajar con esta skill
Revisa semántica, foco y teclado, etiquetas, contraste y el flujo completo. Automatiza lo que se pueda y marca explícitamente lo que exige validación manual. Cita el criterio WCAG afectado y el elemento concreto.

## Formato de salida
- Concreta, sin prosa de relleno.
- Cada afirmación acompañada de su evidencia o criterio de aceptación.
